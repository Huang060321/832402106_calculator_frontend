# Prism Calc 前端

Prism Calc 是“前后端分离计算器系统”的可视化 Web 客户端。前端只收集表达式、调用后端 API、展示结果和管理历史界面；最终计算结果绝不在浏览器中生成。

## 技术栈

- HTML5
- CSS3（Grid、Flexbox、CSS 自定义属性、响应式布局）
- 原生 JavaScript（Fetch API、无前端框架依赖）

## 功能

- 可输入或点击按键构造数学表达式
- 加、减、乘、除、小数、括号和一元正负号
- 科学计算入口：幂、取模、三角函数、平方根、对数和常数
- 后端计算结果和错误消息展示
- 关系数据库历史记录列表、搜索、分页、回填、指定删除和全部清空
- 后端连接状态、键盘快捷键、复制结果、深浅主题
- 桌面端、平板和手机端响应式布局

主题偏好保存在 `localStorage`，但计算历史始终以后端数据库为唯一真实来源。

## 本地启动

先按后端仓库 README 启动 API，再在本仓库根目录执行：

~~~powershell
python -m http.server 5500
~~~

访问 `http://127.0.0.1:5500`。本地 5500 端口会自动连接 `http://127.0.0.1:8000`。

请勿直接双击 `index.html` 作为正式运行方式；使用 HTTP 静态服务器才能得到与部署环境一致的行为。

## 配置后端地址

线上前后端不在同一域名时：

1. 打开仓库自带的 `config.js`。
2. 把其中的空字符串改为已部署后端的 HTTPS 地址，不要以 `/` 结尾。
3. 在后端 `CALCULATOR_CORS_ORIGINS` 中加入前端完整源地址。

如果前端和 API 由同一域名反向代理，保持空字符串即可，前端会请求同源 `/api/...`。

## API 依赖

前端调用以下接口：

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| POST | `/api/calculate` | 提交表达式并获取后端结果 |
| GET | `/api/history` | 获取、搜索和分页显示历史 |
| GET | `/api/history/stats` | 获取累计计算次数 |
| DELETE | `/api/history/{id}` | 删除指定记录 |
| DELETE | `/api/history` | 清空全部记录 |

若后端停止，前端仍可输入和操作按钮，但无法获得新结果，符合前后端分离验证要求。

## 键盘操作

- `Enter`：提交计算
- `Esc`：清空表达式和结果
- 数字与运算符：在输入框中直接输入
- `Tab` / `Shift + Tab`：无鼠标浏览所有交互控件

## 部署

本项目是纯静态站点，可部署到 Netlify、Vercel、GitHub Pages 或任意静态服务器。仓库自带 `netlify.toml`，发布目录为仓库根目录。

部署前必须配置后端 HTTPS 地址，并确认后端 CORS 允许该前端域名；HTTPS 前端不能请求 HTTP 后端，否则浏览器会拦截混合内容。

## 验收建议

依次验证 `12+8`、`8-3`、`6*7`、`20/4`、`0.1+0.2`、`1+2*3`、`(1+2)*3`、`-5+8`、`3*-2`、`1/0`、`1++`，再刷新页面并检查历史仍存在，最后删除任意一条记录。
